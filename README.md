## 一句话结论
原文件的图形语言偏早期工程效果图：高饱和霓虹、网格线、黑底。新版素材建议改成“真实水态 + 夜景灯光 + 真实环境尺度”，保留原水型的几何轮廓，不再使用纯效果图。

## 原文件 13 类水型

1. **水幕**：形成薄水膜/雾幕，可承载影像与灯光，偏沉浸式视觉界面。
2. **高喷**：高而直的粗壮主水柱，作为全场视觉中心与尺度锚点。
3. **彩虹贯日**：双侧抛物线水柱在中间交汇，形成拱门/彩虹式大跨度轮廓。
4. **辅喷**：在主喷两侧或周围辅助构图，增强高度、节奏和对称感。
5. **雪松**：多股竖向水柱叠加细碎水雾，形成树冠式层次。
6. **一维横摇**：喷头在同一平面内往复摆动，形成连续横向水扇。
7. **一维圆摇**：喷头绕轴/沿圆环运动，形成有纵深的立体水幕。
8. **千手观音（一维）**：成排水柱按序展开，像层层手臂/花瓣向外铺开。
9. **蒸蒸日上**：中央水柱群密集上冲，强调上升、爆发与庆典感。
10. **外喷花篮**：水流由中心向外弯曲喷出，形成花篮/花冠式开口。
11. **跑泉**：各组水柱依次起落，用时间差形成“奔跑”的线性动势。
12. **礼花绽放**：中心强喷配合四周放射水柱，像礼花炸开。
13. **孔雀开屏**：多个扇形水幕并排展开，羽毛感来自重复的弧线节奏。
